`surveying.levelling.closure_adjustment` · version 1

Closes a levelling run on the known elevation of its last point: the closure error e = computed − known (positive when the run came out too high), the total length of the run, and a correction to each computed elevation proportional to the distance run, c = −e·(distance so far)/(total length). The adjusted last elevation equals the known one. A closed loop is the same calculation with the start elevation as the closing elevation.

## Inputs

| Name | Meaning | Dimension | Unit | Required | Domain (SI) |
|---|---|---|---|---|---|
| `elevations` | Computed elevation of each point, in order of observation; the last is the point whose elevation is known | list of L | m | yes | any |
| `section_lengths` | Length of the route from the previous point (the start benchmark for point 1) to each point, e.g. the backsight distance plus the foresight distance of the setup | list of L | m | yes | > 0 |
| `closing_elevation` | Known elevation of the last point | L | m | yes | any |

**List group `points`** (one entry per point, at least 1): `elevations`, `section_lengths`. Points whose elevations were computed from the start benchmark, in order of observation. The last point is the one whose elevation is also known.

## Outputs

| Name | Meaning | Dimension | Unit | Shape |
|---|---|---|---|---|
| `closure_error` | Closure error e = computed − known elevation of the last point (signed) | L | m | scalar |
| `total_length` | Total length of the run, L = Σ section lengths | L | m | scalar |
| `corrections` | Correction to each elevation, −e·(cumulative length)/L | L | m | list: one per point (length of `points`) |
| `adjusted_elevations` | Computed elevation of each point plus its correction | L | m | list: one per point (length of `points`) |

## Method

The steps of the calculation, in order, as its trace records them (worked example below):

1. `L = Σs`
2. `e = Z_n − Z_known`
3. `for each point: correction = −e·S/L`
4. `for each point: adjusted elevation = Z + correction`

## Validity and limits

- Every input is checked against its mathematical domain (table above); a value outside it is an `OUT_OF_DOMAIN` error.
- Validity range: none is stated, because no reliable source for one has been established. The mathematical domain of every input is still enforced.

## Assumptions

- Errors accumulate in proportion to the distance run, so the closure error is shared out by cumulative length.
- The closing elevation is the known elevation of the last point; the start benchmark is not adjusted.
- No permissible-closure test is applied: the allowable misclosure depends on the class of work and is not part of this calculation.
